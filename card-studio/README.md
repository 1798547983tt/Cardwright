# 制卡工坊内置资源

这个目录随 Cardwright 打包，是制卡工坊的只读资源。分区 AI 可以读取，但它不会复制进卡项目，用户也不能在界面里修改。每张卡的个性化要求写进该卡的设计书，不改这里的文件。

| 目录 | 内容 | 状态 |
| --- | --- | --- |
| `prompts/` | 内置提示词：`通用规则.md` 与各分区的专用提示词 | 阶段 1：通用规则、规划两份 |
| `knowledge/` | 制卡知识库，原创编写，每篇注明适用版本和核对日期 | 阶段 1：骨架与「00-卡项目与文件约定」 |
| `styles/` | 风格预设规范与反八股清单 | 阶段 3 |
| `frontend/` | 前端骨架：运行时、结构样式、八套皮肤、区块词汇与样例 | 1.1.0 |
| `re0/` | Re0 范例库：结构分析、精选样本、前端与脚本代码 | 阶段 2–3 |
| `samples/` | 范例库：用户本人角色卡里前端做法的原创分析（`龙族/悬浮应用.md`、`煌天厚土/正文内状态头.md`），只收结构、改写的片段与取舍 | 1.1.0 |
| `fixed/` | 固定件：MVU 脚本、Zod 注册头、变量列表条目、只发送最新 N 楼正则 | 阶段 3 |
| `sources.md` | 参考来源清单 | 持续更新 |

## 写作规则

- 知识库只取与制卡有关的事实，用自己的文字按分区任务组织，不逐段改写他人资料（ADR 0011）。
- 酒馆行为相关的事实，先在真实 SillyTavern 里验证，再写进知识库。
- 提示词与界面用语使用 CONTEXT.md「制卡工坊」一节的词表。
