# 复古电影 · cinema

温暖的叙事感：暖黑底、铜橙强调、发丝线、轨道圆环与四角星。适合年代、悬疑、旅途、文学与情感向的卡。

## 令牌

```css
:root {
  --bg: #15110e;          /* 暖黑 */
  --panel: #1c1713;
  --panel-2: #241d17;
  --text: #efe4d6;
  --text-2: #a89886;
  --text-3: #746654;
  --accent: #d8742f;      /* 主色 · 铜橙：当前项、关键数字、主按钮 */
  --accent-2: #b89a6e;    /* 辅色 · 香槟：同一暖色系，只作次级标记 */
  --line: rgba(168, 131, 90, .55);      /* 铜色发丝线 */
  --line-soft: rgba(168, 131, 90, .25);
  --ok: #8fb07a; --warn: #e0a24a; --danger: #cf5a4e;   /* 只用于状态标记 */
  --radius: 2px;
  --serif: "Noto Serif SC", "Source Han Serif SC", "STZhongsong", SimSun, serif;
  --sans: "Microsoft YaHei UI", "Microsoft YaHei", "PingFang SC", sans-serif;
  --display: "Sitka Banner", "Didot", Georgia, serif;   /* 高反差衬线，仅西文 */
}
```

## 版式

- 展示字：西文用 `--display`，字距 0.3–0.5em，全大写，字号大但字重轻。
- 中文标题：宋体，字距 0.1em，不加粗到极端。
- 正文：行高 1.9，段落之间留白大，一屏不塞满。
- 引文或独白：左侧 1px 铜线 + 斜体，颜色 `--text-2`。

## 线框与纹理

- 面板：1px `--line-soft`，圆角 0–2px，不加阴影。
- 发丝线：0.5–1px 的铜色线，用于分隔、下划和边框。
- 胶片颗粒：SVG 噪点叠加，`opacity: .1`、`mix-blend-mode: overlay`，整屏一层就够。
- 轨道圆环：1px 铜线画的椭圆，配 `transform: rotateX(...)` 做出透视；只作背景装饰，不承载信息。

## 装饰元素

- 四角星：4 条尖角的星形（`clip-path: polygon(...)`），`--accent` 色，8–12px，用于标记重点。
- 描边胶囊按钮：1px 铜线，圆角 999px，文字 `--text`，悬停时底色变 `--panel-2`。
- 章节标记：罗马数字或 `第一幕` 写在细线上方，极小号。
- 当前项：文字变 `--accent`，下方一条 1px 铜线延伸。

## 动效

- 慢速淡入：420ms 透明度 + 3px 上移，缓动 `cubic-bezier(.22,1,.36,1)`。
- 光晕呼吸：强调点（四角星、圆环）的透明度在 0.6–1 之间 4s 循环一次，幅度要小。
- 转场：像老电影切镜头一样，200ms 的轻微横移。
- 悬停：描边胶囊的底色 200ms 过渡到 `--panel-2`。
- 不要弹跳、不要旋转、不要闪烁。`prefers-reduced-motion` 时停掉光晕呼吸，只留淡入。

## 禁用

- 紫蓝或粉紫渐变（这套容易被写成「赛博」，别）。
- 圆角大于 2px 的面板（胶囊按钮除外）。
- 大面积发光、霓虹描边。
- 通铺做旧纸张；颗粒只能是很淡的一层。
- emoji 图标；辅色换成冷色或高饱和的第二彩色（辅色是同一暖色系的香槟）。
