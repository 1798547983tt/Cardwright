# 风格预设

卡的前端（状态栏、正文美化、创角页、控制器面板）用同一套风格预设，这样一张卡看起来是一件东西，而不是四个人各做各的。

## 怎么用

1. 规划分区在设计书里定下用哪一套：`tactical`（战术档案）、`gilded`（鎏金典狱）、`terminal`（工业终端）、`cinema`（复古电影），或 `custom`（题材自定）。
2. 前端分区开工前读这里对应的那一篇，把「令牌」表原样抄进 HTML 的 `:root`，再按「版式」「装饰」「动效」写。
3. 每套都要遵守 [反八股清单.md](反八股清单.md)。清单里的禁令高于任何「更好看」的理由。
4. 选 `custom` 时，规划要在设计书里写全十项：底色、唯一的主强调色、文字色、线框语言、圆角、字体栈、纹理、装饰元素、动效、禁用项。缺项就回规划补，不要临场发挥。

## 五套预设

| id | 名称 | 气质 | 底 / 强调 |
| --- | --- | --- | --- |
| `tactical` | [战术档案](战术档案.md) | 冷静、工程感、编号与路径 | 炭黑 / 青蓝 |
| `gilded` | [鎏金典狱](鎏金典狱.md) | 庄重、档案、金属角饰 | 墨绿或暗棕 / 暗金 |
| `terminal` | [工业终端](工业终端.md) | 明亮、机械、警示色带 | 工业白 / 信号黄 |
| `cinema` | [复古电影](复古电影.md) | 温暖、叙事、发丝线 | 暖黑 / 铜橙 |
| `custom` | [题材自定](题材自定.md) | 按题材推导 | 设计书里写 |

## 所有预设共同的底线

- **圆角不超过 2px**。头像和胶囊按钮除外。
- **只有一个强调色**，用在当前项、关键数字和主按钮上。信息层次靠字重、字号和留白拉开，不靠第二个彩色。
- **1px 细线**分割画面，不要用阴影堆出「卡片」。
- 中文是正文主体，英文只作极小的注记；装饰性英文旁边一定有中文。
- 字体一律用系统字体栈兜底。可选的字体 CDN 必须在国内网络下验证可用，**不用 Google Fonts**。
- 纹理、边框、图标用 CSS/SVG 自己画。立绘与音乐只用用户提供的链接，不把大图以 base64 塞进正则。
- 手机宽度（375px）下单列可用，不横向滚动，点击区域不小于 32px。
- 每个前端都自带错误面板，样式沿用本预设。

## 这些预设从哪来

这是 Cardwright 自己写的设计规范，参考的是国产二次元游戏官网**共同的设计语言**（细线、编号、单一强调色、大字作纹理）。**不使用任何游戏或公司的 logo、字体文件、美术素材和商标**，也不模仿具体某一页的版面。名称和色值都是本项目自定的。
