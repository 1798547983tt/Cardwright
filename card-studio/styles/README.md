# 风格预设

卡的前端（状态栏、正文美化、创角页、控制器面板）用同一套风格预设，这样一张卡看起来是一件东西，而不是四个人各做各的。

质感的标准是用户本人那张 Re0 卡的前端：令牌成套、层次清楚、状态有动效、处处有交互反馈、手机上也能用。学它的做法，不照搬它的版面、配色和素材。

## 怎么用

1. 规划分区在设计书的「风格预设」一节写明用哪一套，写 id 或名称都可以：`tactical`（战术档案）、`gilded`（鎏金典狱）、`terminal`（工业终端）、`cinema`（复古电影）、`sakura`（粉樱）、`washi`（和纸）、`neon`（霓虹夜），或 `custom`（题材自定）。应用从这一节读出预设，显示在卡项目主页的色样里。
2. 前端分区开工前读本文件和对应的那一篇：把「令牌」表原样抄进 HTML 的 `:root`，再按「版式」「线框与纹理」「装饰元素」「动效」写。**令牌名不要改**（可以统一加卡名前缀，如 `--xy-bg`），拼装检查按这些名字核对对比度。
3. 下面「必须做到」的每一条都要做到；[反八股清单.md](反八股清单.md) 里的禁令不能破。预设自己的「禁用」一节是这套风格的取舍，也要照做。
4. 选 `custom` 时，规划要在设计书里写全[题材自定](题材自定.md)列出的各项，缺项就回规划补，不要临场发挥。

## 必须做到

每个前端都要做到下面十条。带「检查」的，拼装检查会逐个前端核对：错误禁止导出，警告列出来提醒。

1. **设计令牌成套。** `:root` 里至少定义底（`--bg`）、面板（`--panel`）、线（`--line`）、三级文字（`--text`、`--text-2`、`--text-3`）、主色（`--accent`）、辅色（`--accent-2`）、状态色（`--ok`、`--warn`、`--danger`），外加圆角与字体栈；别处一律用 `var()` 取值，不散落写死的色值。（检查：令牌少于 12 个是警告）
2. **颜色分三档。** 主色只给当前状态、主要操作和关键数字；辅色做辅助标记（进度、次级数值、链接）；状态色只表示成功、警示、危险。信息层次首先靠字号、字重和留白。（检查：`var(--accent)` 用了 8 处以上是警告）
3. **交互反馈看得见。** 可以点的东西都有 `:hover`、`:active` 和 `:focus-visible` 的样子，点下去有反应；点击区域不小于 32px。（检查：整个前端一处 `:hover`/`:active`/`:focus` 都没有、也没有事件监听，是错误）
4. **至少一处克制的动效。** 进入、切换或数值变化里至少有一个过渡；并且写 `@media (prefers-reduced-motion: reduce)`，在里面关掉位移、缩放和循环，只留透明度。循环动画整屏最多一个。（检查：有循环动画却没写 `prefers-reduced-motion` 是警告）
5. **空值兜底。** 变量缺失、为空或类型不对时显示「未知」或「—」，不崩成空白，也不补造内容。
6. **375px 单列可用。** 手机宽度下折成一列、不横向滚动；定宽只写进 `@media (min-width: …)`，宽表格外面包一层 `overflow-x: auto` 的容器。至少有一个 `@media`。（检查：比 375px 宽的固定宽度、没有横向滚动容器的七列以上表格是错误；没有任何 `@media` 是警告）
7. **正文对比度不低于 4.5:1。** `--text` 放在 `--bg` 和 `--panel` 上都要达到 4.5:1；次级文字也尽量不低于 3:1。（检查：`:root` 里的正文色对底色、面板色低于 4.5:1 是错误）
8. **系统字体栈。** 中文、西文、等宽三条都带系统字体兜底，不用 Google Fonts。（检查：错误）
9. **素材自己画。** 纹理、边框、图标用 CSS/SVG 画；立绘、头像、音乐只用设计书里给的链接，不把大图以 base64 塞进替换内容。（检查：16 KB 以上的 base64 文件是错误）
10. **自带错误面板。** 解析或渲染出错时显示可读的错误区和【复制报错】按钮，样式沿用本预设。

## 从 Re0 学什么

- 令牌写在一处、分主题切换，改一个色值全卡跟着变。
- 圆角、渐变和阴影都可以用，但每一处都有用途：圆角区分可点的控件，渐变只做进度和光晕，阴影只分一层。
- 状态有动效：数值变化会过渡，展开收起有节奏，加载有占位。
- 交互反馈处处都在：悬停、按下、聚焦、禁用四种样子写全。
- 窄屏有专门的排法，而不是把宽屏缩小。

## 这些预设从哪来

这是 Cardwright 自己写的设计规范。战术档案、鎏金典狱、工业终端、复古电影参考国产二次元游戏官网**共同的设计语言**；粉樱、和纸、霓虹夜按题材的实物与氛围推导（春日校园、书卷与印章、夜色中的屏幕）。**不使用任何游戏或公司的 logo、字体文件、美术素材和商标**，也不模仿具体某一页的版面。名称和色值都是本项目自定的。
