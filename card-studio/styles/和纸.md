# 和纸 · washi

素净的书卷感：米白纸色、墨色正文、朱红印章、细竖线分栏、大量留白。适合和风、仙侠、古风、志怪与书信体的卡。

## 令牌

```css
:root {
  --bg: #f3ede1;          /* 米白：生纸色 */
  --panel: #faf6ee;       /* 面板：浅纸 */
  --panel-2: #ece3d2;     /* 次级面板、表头 */
  --line: rgba(60, 44, 32, .18);        /* 细竖线、分隔 */
  --line-strong: rgba(60, 44, 32, .42);
  --text: #2a2420;        /* 墨色 */
  --text-2: #5c5249;      /* 淡墨 */
  --text-3: #857a6e;      /* 更淡的注记 */
  --accent: #c23a2b;      /* 主色 · 朱红：印章、当前项、关键数字 */
  --accent-2: #33587a;    /* 辅色 · 藍：地名、链接、辅助标记 */
  --ok: #4d7a52; --warn: #b7791f; --danger: #a3261c;   /* 只用于状态标记 */
  --radius: 3px;
  --serif: "Noto Serif SC", "Source Han Serif SC", "STSong", SimSun, serif;
  --kai: "KaiTi", "STKaiti", "Noto Serif SC", serif;   /* 楷体，只用于题签与引文 */
  --sans: "Microsoft YaHei UI", "Microsoft YaHei", "PingFang SC", sans-serif;
}
```

纸色是底，墨色是字，朱红只盖在要紧处——像一页批过的书稿。

## 版式

- 标题：宋体或楷体，字距 0.12em，字重不超过 600；三级字号 22px / 16px / 13px。
- 竖排：宽屏时章节标题、人物名可以竖排（`writing-mode: vertical-rl`），放在栏的右侧；375px 下一律改回横排。
- 正文：宋体 15–16px，行高 1.9，段首不缩进、段间空半行。
- 分栏：信息用「细竖线分栏」排，栏与栏之间 1px `--line` 竖线；手机上栏变成上下排列，竖线变成横线。
- 数字：日期与数量用汉字或等宽数字，全卡统一一种。

## 线框与纹理

- 面板：几乎不用框，靠留白和细线分区；需要框时 1px `--line`，圆角 `--radius`。
- 纸纹：SVG `feTurbulence` 生成的纤维噪点，透明度不超过 0.06，整页一层。
- 题签：竖长条 1px `--line-strong` 边框，里面写楷体的书名、章名或人名。
- 不做旧、不撕边、不烧焦——纸是干净的新纸。

## 装饰元素

- 朱印：正方形，`--accent` 底白字或朱线框朱字，微旋 -4°，用于「当前」「已定」「危」这类一两个字的标记。
- 分隔：细线中间一个小圆点，或一枚菱形的「·」。
- 云纹、水纹、竹叶：用 SVG 线稿画，1px `--line-strong`，只作角落点缀，一屏一处。
- 引文：左侧 1px 朱线，楷体，颜色 `--text-2`。
- 地名、物名：`--accent-2` 字加 1px 点线下划线，悬停显示注释。

## 动效

- 进入：墨晕——透明度 0→1 加 `filter: blur(2px)` 到 0，280ms，缓动 `ease-out`。
- 盖印：状态变化时朱印从 1.15 缩到 1、透明度 0→1，180ms，只放一次。
- 下划线：悬停时像毛笔一样从左到右 320ms 画出（`transform: scaleX()`，`transform-origin: left`）。
- 不要循环动画。`prefers-reduced-motion` 时去掉模糊与缩放，只留透明度。

## 禁用

- 大红大金堆砌的「中国风」、龙纹和祥云铺满整屏。
- 通铺做旧纸、撕边、烧焦、墨迹喷溅。
- 霓虹发光、毛玻璃、厚重阴影。
- 圆角大于 6px 的面板；emoji 与网图素材当装饰。
- 朱红用于大段正文，或同一屏盖三个以上的印。
