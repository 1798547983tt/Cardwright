# 题材自定 · custom

七套预设都不贴题材时，由规划分区按作品与资料推导一套，写进设计书。前端分区按设计书实现，不在前端里临场发挥。

## 设计书里必须写全的各项

| 项目 | 要求 | 例子 |
| --- | --- | --- |
| 1 底色 | 页面底、面板、次级面板三个色值 | `#0f1412` / `#161d1a` / `#1d2622` |
| 2 主色与辅色 | 主色一个，写明用在哪（当前项、关键数字、主按钮）；辅色一个，写明它只作哪些辅助标记 | 主 `#5fbf9b`；辅 `#8fa6c9`，只用于进度与链接 |
| 3 文字色 | 正文、次要、更弱三级；正文对底色、面板色都不低于 4.5:1 | `#e8efe9` / `#94a89c` / `#5f6f66` |
| 4 状态色 | 成功、警示、危险三个，只用于状态 | `#4fb477` / `#e0a33c` / `#d4545f` |
| 5 线框语言 | 线宽、线色、有没有内描边、角饰形状；阴影写 `--shadow`，不要阴影就写 none | 1px `rgba(95,191,155,.3)`，四角短折线 |
| 6 圆角 | 面板、按钮、标签各多少，全卡统一；按钮圆角写 `--radius-sm` | 面板 4px，按钮 4px，标签胶囊 |
| 7 字体栈 | 中文、西文、等宽三条，全部带系统兜底 | 见下方模板 |
| 8 纹理 | 什么纹理、铺在哪、透明度上限 | 极淡网点，仅面板头部，≤ 0.06 |
| 9 装饰元素 | 3–5 种，写清尺寸与用途 | 编号块、方括号标签、分隔菱形 |
| 10 动效 | 进入、悬停与按下、数值变化三类，各写时长与缓动；写明减少动画时保留什么 | 进入 200ms ease-out… |
| 11 禁用项 | 这套明确不要的东西 | 不用发光、不用第二层阴影 |

## 令牌模板

```css
:root {
  --bg: ;
  --panel: ;
  --panel-2: ;
  --line: ;
  --line-strong: ;
  --text: ;
  --text-2: ;
  --text-3: ;
  --accent: ;             /* 主色 */
  --accent-2: ;           /* 辅色 */
  --ok: ; --warn: ; --danger: ;
  --radius: ;
  --radius-sm: ;          /* 按钮、标签 */
  --shadow: ;             /* 不要阴影就写 none */
  --sans: "Microsoft YaHei UI", "Microsoft YaHei", "PingFang SC", sans-serif;
  --serif: "Noto Serif SC", "Source Han Serif SC", SimSun, serif;
  --mono: "Cascadia Mono", Consolas, monospace;
}
```

令牌名和其他预设一致，拼装检查按这些名字核对对比度。前端写装配单时，前端分区把这些令牌逐个抄进装配单的 `令牌:`（`--bg`、`--panel`、`--line`、`--text`、`--text-2`、`--text-3`、`--accent`、`--accent-2`、`--ok`、`--warn`、`--danger` 这十一个必填，缺了是 `sheet-invalid`）。没写 `--shadow` 时骨架按没有阴影处理，自定义区块里用 `--radius-sm` 时也可以写成 `var(--radius-sm, var(--radius))` 兜底；但题材自定应当把这两个令牌定下来。

## 推导时的注意

- 先找题材里**本来就有的**视觉语言：档案袋、机械铭牌、剧场节目单、航海日志、病历、卷宗、票据、校刊、信笺。从实物出发，比从「科幻风」这种词出发可靠。
- 辅色比主色低一档：饱和度或明度更低，或者用同一色相的明暗两档。要表现两派对立，用主色和辅色各代表一派，不要再加第三种彩色。
- 底色尽量偏中性（近黑、近白或纸色）；彩色留给强调。
- 想好在手机上是什么样：三列信息在 375px 下必须能折成一列。
- 定完后回头对一遍 [README.md](README.md) 的「必须做到」和 [反八股清单.md](反八股清单.md)，逐条确认。

## 仍然适用的硬规则

- 「必须做到」十条全部适用：令牌成套、颜色三档、交互反馈、克制动效与减少动画、空值兜底、375px 单列、正文对比度 4.5:1、系统字体栈、素材自己画、自带错误面板。
- 字体必须有系统兜底，不用 Google Fonts。
- 纹理、图标用 CSS/SVG 画，不引外部图片。
