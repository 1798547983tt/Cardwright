# 题材自定 · custom

四套预设都不贴题材时，由规划分区按作品与资料推导一套，写进设计书。前端分区按设计书实现，不在前端里临场发挥。

## 设计书里必须写全的十项

| 项目 | 要求 | 例子 |
| --- | --- | --- |
| 1 底色 | 页面底、面板、次级面板三个色值 | `#0f1412` / `#161d1a` / `#1d2622` |
| 2 唯一强调色 | 一个，写明用在哪（当前项、关键数字、主按钮） | `#5fbf9b`，只用于这三处 |
| 3 文字色 | 正文、次要、更弱三级 | `#e8efe9` / `#94a89c` / `#5f6f66` |
| 4 线框语言 | 线宽、线色、有没有内描边、角饰形状 | 1px `rgba(95,191,155,.3)`，四角短折线 |
| 5 圆角 | 不超过 2px；写明胶囊按钮的例外 | 面板 0，按钮 2px，胶囊除外 |
| 6 字体栈 | 中文、西文、等宽三条，全部带系统兜底 | 见下方模板 |
| 7 纹理 | 什么纹理、铺在哪、透明度上限 | 极淡网点，仅面板头部，≤ 0.06 |
| 8 装饰元素 | 3–5 种，写清尺寸与用途 | 编号块、方括号标签、分隔菱形 |
| 9 动效 | 入场、切换、强调三类，各写时长与缓动 | 淡入 200ms ease-out… |
| 10 禁用项 | 这套明确不要的东西 | 不用发光、不用第二彩色 |

:root {

## 推导时的注意

- 先找题材里**本来就有的**视觉语言：档案袋、机械铭牌、剧场节目单、航海日志、病历、卷宗、票据。从实物出发，比从「科幻风」这种词出发可靠。
- 一个强调色够用。要表现两派对立，用**同一色相的明暗两档**，不要上两种彩色。
- 底色尽量偏中性（近黑或近白）；彩色留给强调。
- 想好在手机上是什么样：三列信息在 375px 下必须能折成一列。
- 定完后回头对一遍 [反八股清单.md](反八股清单.md)，逐条确认没有踩。

## 仍然适用的硬规则

- 圆角不超过 2px（头像、胶囊按钮除外）。
- 只有一个强调色。
- 字体必须有系统兜底，不用 Google Fonts。
- 纹理、图标用 CSS/SVG 画，不引外部图片。
- 手机宽度可用，自带错误面板。
