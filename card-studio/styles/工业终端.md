# 工业终端 · terminal

明亮的机械感：工业白底、黑线、信号黄色带、方括号标签与分页。适合末世工业、建造经营、生存与调查题材。

## 令牌

```css
:root {
  --bg: #f1f1ee;          /* 工业白 */
  --panel: #ffffff;
  --panel-2: #e3e4e0;     /* 浅灰分区 */
  --text: #121212;
  --text-2: #55585a;
  --text-3: #74777a;
  --accent: #ffe100;      /* 主色 · 信号黄：只作色带与高亮底 */
  --accent-2: #2459c4;    /* 辅色 · 蓝图蓝：链接、坐标、次级数值 */
  --ink: #121212;         /* 黑色色带、线 */
  --line: rgba(18, 18, 18, .18);
  --line-strong: #121212;
  --ok: #1f8a4c; --warn: #b86b00; --danger: #c62828;   /* 只用于状态标记 */
  --radius: 0px;
  --sans: "Bahnschrift", "Microsoft YaHei UI", "PingFang SC", sans-serif;
  --mono: "Cascadia Mono", Consolas, monospace;
}
```

这是整套预设里唯一的浅色方案。信号黄是**底**不是**字**：黄底黑字，不要黄字。

## 版式

- 标题：窄体（`font-stretch: condensed` 或 Bahnschrift），黑色，字重 800，字距 0.02em。
- 关键标题压在黄色色带上：`background: var(--accent); color: var(--ink); padding: 2px 10px`。
- 方括号标签：`[ 状态 ]`、`[ 已封锁 ]`，等宽字体，黑色。
- 分页与计数：`1 / 33` 写法，等宽字体，右上角。
- 数据一律等宽字体，右对齐。

## 线框与纹理

- 面板：1px 黑线，直角，白底。不加阴影。
- 斜线填充：`repeating-linear-gradient(-45deg, #121212 0 1px, transparent 1px 6px)`，透明度压到 0.12–0.2，用于「无数据」「禁止进入」这类区域。
- 十字准星：两条 1px 黑线交叉，配一个 1px 描边的圆，用于焦点或坐标。
- 机械线稿：用 SVG 画的直角折线、螺栓点（2px 实心圆），不要写实图片。

## 装饰元素

- 危险色带：整行黄底黑字，用于警告或当前步骤，一屏最多一条。
- 编号块：黑底白字的小方块，放在标题左侧。
- 分隔：整行 1px 黑线；次级分隔用 `--line`。
- 当前项：黄色底或黑色底反白，二选一，全卡统一。

## 动效

- 步进切换：80ms 的硬切（`steps(2)`），不要缓入缓出。
- 扫描：一条 2px 的黑线从上到下扫过一次，600ms，只在加载时放。
- 计数跳动：数字变化时用等宽字体逐位翻动，100ms。
- 按下：按钮整体下沉 1px，黑线加粗到 2px，60ms。
- 不要淡入淡出、不要弹性缓动。`prefers-reduced-motion` 时去掉扫描与翻动，直接显示结果。

## 禁用

- 黄字（黄色只作底色与 2px 短线）。
- 圆角、阴影、渐变、毛玻璃。
- 大面积纯黑铺底（这是浅色方案，黑色只用于字、线和小色块）。
- emoji 图标；把黄色当成第二个正文色。

> 注意：这套是给**卡的前端**用的。制卡工坊自己的界面是深色卷宗风，两者不要互相靠拢。
