# 霓虹夜 · neon

夜色里的屏幕：近黑偏蓝的底、青色主色、紫色作辅、克制的发光、角标与数据条。适合赛博、都市异能、近未来、黑客与夜城题材的卡。

## 令牌

```css
:root {
  --bg: #0a0b12;          /* 夜底：近黑偏蓝 */
  --panel: #11131f;       /* 面板 */
  --panel-2: #171a2a;     /* 次级面板、选中底 */
  --line: rgba(130, 150, 255, .18);
  --line-strong: rgba(130, 150, 255, .34);
  --text: #e7eaf6;        /* 正文 */
  --text-2: #9ba3c6;      /* 次要文字 */
  --text-3: #69719a;      /* 注记 */
  --accent: #2fe0f0;      /* 主色 · 青：当前项、主操作、关键数字 */
  --accent-2: #a970ff;    /* 辅色 · 紫：加成、上限、次级数值 */
  --ok: #39d98a; --warn: #ffb547; --danger: #ff5577;   /* 只用于状态灯与短标记 */
  --glow: 0 0 10px rgba(47, 224, 240, .35);   /* 唯一允许的发光：当前项与焦点 */
  --radius: 6px;
  --sans: "Microsoft YaHei UI", "Microsoft YaHei", "PingFang SC", sans-serif;
  --mono: "Cascadia Mono", Consolas, "Noto Sans Mono", monospace;
  --latin: "Bahnschrift", "DIN Alternate", Arial Narrow, sans-serif;   /* 窄体，只用于大写英文注记 */
}
```

光是稀缺的：整屏只有当前项和获得焦点的控件会发光，其余都是细线和实色。

## 版式

- 标题：黑体粗体，三级字号 22px / 15px / 12px；可以跟一个窄体大写英文注记，例如 `据点 [ SECTOR 07 ]`，英文颜色 `--text-3`。
- 数字：一律等宽字体、右对齐，单位小一号。
- 分区：HUD 式排布，关键区域用四角折线框出来；信息密度可以高，但每块只有一个焦点。
- 标签：方括号包住的等宽小字 `[ 在线 ]`，不用胶囊底。
- 375px 下一列，HUD 角标缩小到 6px。

## 线框与纹理

- 面板：1px `--line` 边框，圆角 `--radius`，底色 `--panel`。
- 当前项：1px `--accent` 边框 + `--glow`，底色 `--panel-2`。
- 扫描线：`repeating-linear-gradient(transparent 0 3px, rgba(255, 255, 255, .025) 3px 4px)` 整页一层，不要更明显。
- 网格：极淡的 24px 网格线只铺在页眉，透明度不超过 0.06。

## 装饰元素

- 角标：四角 8px 的 L 形折线，`--accent`，只框关键区域。
- 数据条：细长条加刻度，青色填充，紫色那一段表示加成或上限。
- 状态灯：6px 圆点，`--ok` / `--warn` / `--danger`，在线状态可以慢闪（见动效）。
- 故障字：标题在进入时做一次 RGB 错位（青、紫各偏 1px），只在进入时一次。

## 动效

- 通电：进入时用 `steps(3)` 明灭一次，160ms，像屏幕亮起来。
- 悬停：边框从 `--line` 过渡到 `--accent`，发光淡入，150ms。
- 数值变化：数字逐位滚动 200ms，数据条同步伸缩。
- 循环：整屏最多一个——在线状态灯 2s 一次的呼吸。`prefers-reduced-motion` 时关掉明灭、故障字和呼吸，只留颜色过渡。

## 禁用

- 满屏发光、每个元素都描霓虹边、文字阴影。
- 青紫大渐变铺底（渐变只用于细线和数据条）。
- 纯白正文（用 `--text`）、纯黑底（用 `--bg`）。
- emoji 图标；为了「赛博感」堆整屏英文——英文只作注记，旁边要有中文。
- 高频闪烁（每秒超过三次的明暗变化会让人不适，也可能诱发光敏反应）。
