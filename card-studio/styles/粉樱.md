# 粉樱 · sakura

柔和明快的春日感：樱花白底、樱粉主色、嫩叶绿作辅、圆润的面板和胶囊。适合日常、恋爱、校园、治愈与轻喜剧的卡。

## 令牌

```css
:root {
  --bg: #fff7f9;          /* 樱花白：页面底 */
  --panel: #ffffff;       /* 面板 */
  --panel-2: #ffeef3;     /* 次级面板、选中底、标签底 */
  --line: #f3d3dd;        /* 1px 细线 */
  --line-strong: #e9b3c4;
  --text: #3f2a33;        /* 正文：深莓棕，不用纯黑 */
  --text-2: #7b5b68;      /* 次要文字 */
  --text-3: #a3838f;      /* 注记、占位 */
  --accent: #e2517f;      /* 主色 · 樱粉：当前项、主按钮、关键数字 */
  --accent-2: #5f9e7c;    /* 辅色 · 嫩叶绿：进度、成就、次级标记 */
  --ok: #3f9a6b; --warn: #d98a2b; --danger: #d64550;   /* 只用于状态标记 */
  --radius: 14px;         /* 面板 */
  --radius-sm: 8px;       /* 按钮、输入框 */
  --shadow: 0 6px 18px rgba(226, 81, 127, .10);   /* 全卡唯一的一层阴影 */
  --sans: "Microsoft YaHei UI", "Microsoft YaHei", "PingFang SC", "Noto Sans SC", sans-serif;
  --round: "YouYuan", "Microsoft YaHei UI", "PingFang SC", sans-serif;   /* 圆体，只用于标题 */
  --mono: "Cascadia Mono", Consolas, monospace;
}
```

这是浅色方案。樱粉是点睛的颜色，不是底色：大面积用樱花白和纯白，粉色只落在当前项、主按钮和关键数字上。

## 版式

- 标题：圆体或黑体中粗，三级字号 20px / 15px / 13px，字距 0.02em，颜色 `--text`。
- 正文：15px，行高 1.8；对白与独白可以放进气泡框，旁白不放。
- 信息按「面板 + 标签」组织：一块信息一张圆角面板，面板之间 12px 间距；宽屏最多两列，375px 下一列。
- 数值用等宽字体，右侧跟一个小号单位；好感度、心情这类数值配胶囊进度条。
- 时间、地点写在页眉一行，小号 `--text-2`，前面一个 SVG 小图标。

## 线框与纹理

- 面板：1px `--line` 边框 + `--shadow`，圆角 `--radius`。全卡只有这一层阴影，面板里面不再套阴影。
- 选中项：底色 `--panel-2`，左侧 3px 圆头竖条 `--accent`。
- 纹理：页眉可以铺一层极淡的樱瓣点阵（SVG 画五瓣小花，透明度不超过 0.08），正文区保持干净。
- 分隔：1px `--line` 细线，或 8px 的留白，不用粗线。

## 装饰元素

- 胶囊标签：`--panel-2` 底、`--accent` 字、圆角 999px，用于身份、关系、天气这类短词。
- 樱瓣与心形：用 SVG 画，12–16px，只放在标题旁或当前项上，一屏不超过三处。
- 胶囊进度条：圆头，轨道 `--line`，填充 `--accent`；加成部分用 `--accent-2` 叠一段。
- 气泡框：圆角 14px，一侧带 8px 的小尾巴，用于角色独白或提示。
- 头像：圆形，1px `--line-strong` 描边，当前说话的人加一圈 2px `--accent`。

## 动效

- 进入：240ms 透明度 + 4px 上移，缓动 `cubic-bezier(.2, .8, .2, 1)`。
- 悬停：卡片和按钮上浮 2px，阴影略加深，150ms。
- 按下：120ms 缩到 0.97 再回到 1，像轻轻按下一个软按钮。
- 数值变化：进度条 360ms 缓动到新值，数字同时滚动。
- 循环：整屏最多一个——页眉一片樱瓣缓慢飘落（12s 一次，透明度不超过 0.5）。`prefers-reduced-motion` 时停掉飘落、上浮和缩放，只留透明度过渡。

## 禁用

- 纯黑正文、大面积黑底（这是浅色方案）。
- 荧光粉、满屏粉色底、粉紫渐变铺满整屏。
- 超过一层阴影、毛玻璃、发光描边。
- emoji 当图标（樱花、爱心、星星都用 SVG 画）。
- 把樱粉当正文色；圆角大小不统一（面板一律 `--radius`，按钮一律 `--radius-sm`，标签一律胶囊）。
