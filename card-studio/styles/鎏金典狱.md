# 鎏金典狱 · gilded

庄重的档案感：墨绿或暗棕底、暗金线与角饰、衬线展示字、编号胶囊与印章。适合哥特、宗教、审判、贵族与旧世界题材。

## 令牌

```css
:root {
  --bg: #141a14;          /* 墨绿；暗棕方案用 #1a1612 */
  --panel: #19211a;       /* 面板；暗棕方案用 #221c17 */
  --panel-2: #1f2a20;
  --text: #efe6d2;        /* 象牙 */
  --text-2: #b8a98a;
  --text-3: #7d7460;
  --accent: #d9bb7a;      /* 主色 · 亮金：只用于当前项和关键数字 */
  --accent-2: #b8955a;    /* 辅色 · 暗金：角饰、编号胶囊、次级文字 */
  --line: rgba(184, 149, 90, .45);
  --line-soft: rgba(184, 149, 90, .22);
  --ok: #7fae7a; --warn: #d9a441; --danger: #c8584f;   /* 只用于状态标记 */
  --radius: 2px;
  --serif: "Noto Serif SC", "Source Han Serif SC", "STZhongsong", SimSun, serif;
  --sans: "Microsoft YaHei UI", "Microsoft YaHei", "PingFang SC", sans-serif;
  --display: "Sitka Banner", Georgia, "Times New Roman", serif;  /* 高反差衬线，仅西文 */
}
```

亮金是主色（`--accent`），暗金是辅色与线色（`--accent-2`、`--line`）——两者分工固定，不要互换。

## 版式

- 标题：中文用宋体，字距 0.08em；西文展示字用 `--display`，字距 0.12em，全大写。
- 正文：黑体或宋体均可，行高 1.8，段间距大。
- 编号胶囊：`MBCC-S-525` 这类编号写在 1px `--accent-2` 描边的胶囊里，圆角 999px（胶囊是唯一允许的圆角例外）。
- 关键数字用 `--accent`，字号比正文大一级。

## 线框与纹理

- 面板：1px `--line` 边框 + 内描边（`outline: 1px solid var(--line-soft); outline-offset: -3px`），圆角 0–2px。
- 角饰：四角放 45° 旋转的小方块或短折线，用 `--accent-2`，边长 6–8px。
- 画框：椭圆或切角矩形，1px 金线，内侧留 2px 底色的间隙。
- 纹理：**不要通铺羊皮纸**。只允许极淡的斜向噪点（透明度 ≤ 0.06）或单侧的柔光。

## 装饰元素

- 印章：文字加 1px 边框、旋转 -12°~-15°、`--accent-2` 色，用于「危险等级」「已封存」这类标记。
- 点线引导：`border-bottom: 1px dotted var(--line-soft)`，把标签和值连起来。
- 分隔：中间带一个菱形的水平线（线 + 45° 小方块）。
- 当前项：底色 `--panel-2`，标题变 `--accent`，左侧加金色竖条。

## 动效

- 淡入：320ms 透明度 + 2px 上移，缓动 `ease-out`。
- 金属光泽：从左到右 900ms 掠过一次的窄高光（`linear-gradient` + `transform: translateX()`），只在展开或提交这类关键时刻放一次，不循环。
- 悬停：金线从 `--line-soft` 过渡到 `--line`，200ms。
- 不要闪烁、不要多个元素同时动。`prefers-reduced-motion` 时去掉位移与光泽，只留淡入。

## 禁用

- 通铺羊皮纸、做旧纸张、大面积渐变。
- 圆角超过 2px 的面板（胶囊按钮除外）。
- 金色泛滥：金色只出现在线、角饰、编号和当前项上，正文一律用象牙色。
- emoji 图标；用金色阴影或发光代替线条。
