# 战术档案 · tactical

冷静的工程感：炭黑底、一种青蓝、编号与路径、低对比巨字当底纹。适合硬科幻、都市异能、组织与任务驱动的卡。

## 令牌

```css
:root {
  --bg: #101214;          /* 页面底 */
  --panel: #171a1d;       /* 面板 */
  --panel-2: #1d2125;     /* 次级面板、表头 */
  --text: #e9ecee;        /* 正文 */
  --text-2: #8b949b;      /* 次要文字、注记 */
  --dim: #5b646b;         /* 更弱的说明 */
  --accent: #19a7e8;      /* 唯一强调色 */
  --line: rgba(255, 255, 255, .14);   /* 1px 细线 */
  --line-strong: rgba(255, 255, 255, .28);
  --ok: #4fb477; --warn: #e0a33c; --bad: #d4545f;   /* 只用于状态点，不参与版面 */
  --radius: 0px;
  --sans: "Microsoft YaHei UI", "Microsoft YaHei", "PingFang SC", "Noto Sans SC", sans-serif;
  --mono: "Cascadia Mono", Consolas, "Noto Sans Mono", monospace;
  --latin: "Bahnschrift", "DIN Alternate", Arial Narrow, sans-serif;  /* 窄体，只用于大写英文 */
}
```

状态色只用在小圆点或一两个字上，不要拿去铺底、描边或做按钮。

## 版式

- 标题：中文黑体加粗，字号拉开（例如 22px / 15px / 13px 三级），字距 0.02em。
- 编号：`01 // 05` 的写法，等宽字体，`--text-2` 色，放在标题左上或行首。
- 路径：`档案 // 人物 // 菜月昴` 这样的面包屑，极小号，全大写英文可以跟在中文后面，例如 `档案 ARCHIVE`。
- 数字一律等宽字体，便于纵向对齐。
- 表格式排布：左侧标签 `--text-2`，右侧值 `--text`，中间用 1px 细线分隔，不加背景块。

## 线框与纹理

- 面板只有 1px `--line` 边框，直角，不加阴影。
- 巨字底纹：把关键词用 `--latin` 写成超大字号，颜色 `rgba(233,236,238,.045)`，压在面板底层，**不要**加模糊或渐变。
- 网点：`radial-gradient(rgba(255,255,255,.22) 1px, transparent 1.2px)` + `background-size: 3px 3px`，只铺在小面积区域。
- 需要强调的一行可以在左侧加 2px 的 `--accent` 竖条。

## 装饰元素

- 当前项：整行底色 `--panel-2`，左侧 2px `--accent` 竖条，编号变成 `--accent`。
- 标签：方括号包住的极小号文字 `[ 在线 ]`，不用胶囊背景。
- 分隔：整行 1px 细线，两端留 8px 空白。
- 头像：直角，灰度处理，只有当前项保持彩色。

## 动效

- 切入：120ms 的位移 + 透明度，缓动 `cubic-bezier(.16,1,.3,1)`。
- 分隔线：从左到右 220ms 展开（`transform: scaleX()`，`transform-origin: left`）。
- 编号滚动：数字变化时用 120ms 的上下位移，不要弹跳。
- 不要循环动画、呼吸光、粒子。

## 禁用

- 第二个强调色；用蓝色以外的颜色做按钮。
- 圆角、阴影、毛玻璃、渐变背景。
- emoji 图标；用 emoji 代替状态点。
- 把巨字底纹调到能看清的对比度（它是纹理，不是标题）。
