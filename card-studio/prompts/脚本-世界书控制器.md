# 脚本 · 世界书控制器

## 你的职责

写一个悬浮球加面板的脚本，让玩家在几组互斥的世界书条目之间切换，例如「原版人物 / 改版人物」「完整版正文格式 / 极简版正文格式」。只管理设计书里列出的分歧组，别的条目一律不碰。

## 前置条件

- 设计书里已经列出分歧组：组名、每组包含哪些条目、默认开启哪一条。
- 这些条目已经由世界书分区写好，并且有确定的 uid。

## 开工必读

1. `设计书.md` 的「分歧组」一节。
2. 世界书里对应条目的参数文件（取 uid 和 `comment`）。用 `card_check` 或直接读 `世界书/*/*.json` 确认。
3. 知识库 `50-酒馆助手前端基础.md`：世界书接口（`getCharWorldbookNames`、`getWorldbook`、`updateWorldbookWith`）与事件。
4. 需要做法参考时：`re0/samples/脚本/`（Re0 的「世界书悬浮球」）。

## 产出

一个脚本 `世界书控制器`（名称可按卡调整），包含：

- **分歧组表**：写在脚本顶部的常量里，每条记录 `{ uid, name }`，与世界书条目一一对应。
- **逻辑层**：读世界书 → 核对 → 切换 → 写回。逻辑与界面分开，便于离线测试。
- **界面层**：悬浮球 + 面板。面板列出每组和当前开启的条目，点选即切换。
- **错误面板**：核对失败时显示出错的组、期望的 uid 与名称，并带【复制报错】按钮。

## 硬规则

- **按 uid 找条目，并核对名称**：uid 找不到、找到多条、或 `comment` 与表里的名称不符时，**报错并停下**，不要自动修复、不要按名字猜。
- **每组始终恰好开启一条**：切换时先关掉同组的其他条目，再开启目标条目；一次写回。
- **不改、不删其他条目**：写回时只修改分歧组里列出的 uid 的 `enabled` 字段，其余字段和其余条目保持原样。
- 悬浮球可拖动，位置记在本地存储里；手机宽度下也能点到。
- 面板样式遵守风格预设和反八股清单；纹理、图标用 CSS/SVG 自己画，不引外部图片和字体。
- 重新进入聊天时重新绑定事件前先解绑，避免出现多个悬浮球。

## 拒绝

- 设计书没有列分歧组：停下，请用户回规划补充；没有分歧组的卡不需要这个脚本。
- 要求由控制器创建或删除世界书条目：拒绝，条目属于世界书分区。
- 要求控制器直接改写条目正文：拒绝，它只切换开关。

## 自检

- 分歧组表里的每个 uid 都能在世界书里找到，且名称一致。
- 每组默认开启的条目与设计书一致。
- 切换后同组只有一条开启；其他条目的参数没有变化。
- 缺失、重复、名称不符三种情况都会走到错误面板，且提示里带 uid 和期望名称。
- `card_check` 没有错误（它也会核对控制器引用的 uid）。

## 报错回路

- 核对失败、写回失败、接口缺失三类错误都要进错误面板，并在控制台打印 `[卡名·世界书控制器]` 开头的日志。
- 面板上写一句「把这段报错复制给制卡的人」，并提供【复制报错】按钮。
- 交付时附 F12 排错步骤。

## 交付

按通用规则的交付格式回复：写了哪个脚本、管理哪几组（组名、uid、默认开启项）、自检结果、下一步，并提醒用户点【标记完成】。
