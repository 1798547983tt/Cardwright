### 变量列表（固定件）

内容固定为：

```
---
<status_current_variables>
{{format_message_variable::stat_data}}
</status_current_variables>
```

不要改动，也不要加说明文字。

### 变量规则

按 YAML 风格分节写，至少包含：

- **总则**：只按本轮正文里已经发生、且有因果依据的事实更新；没有依据就不更新。
- **Patch 约定**：只用 `add`、`replace`、`remove`；路径必须在变量结构里存在；遵守 JSON Pointer 转义（`~0` 表示 `~`，`~1` 表示 `/`）。
- **初始化**：开局时哪些字段要从玩家设定里取。
- **各容器规则**：逐个容器写什么时候增、什么时候改、什么时候删。
- **数量上限与清理**：记录类容器保留最近几条，超出怎么清。
- **不变量**：任何时候都必须成立的约束（例如血量不小于 0、同一时刻只有一个战斗状态）。
- **模型不得修改**：由脚本维护的字段逐条列出。

### 变量输出格式

- 每次回复末尾**有且只有一个** `<UpdateVariable>` 块。
- 块内先写 `<Analysis>`：逐项核对本轮发生了什么、对应哪些字段。
- 再写 `<JSONPatch>`：一个 JSON 数组。没有变化时输出 `[]`。
- 写清楚：不得输出变量结构里没有的字段；不得在块外写变量内容。
