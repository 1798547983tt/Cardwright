# 装配单词汇

装配单是前端分区写的 YAML 文件，告诉应用怎样编译出状态栏、正文美化或创角页。文件放在正则组件目录下（`正则/<序号>-<名称>.yaml`），以 `前端:` 开头。应用凭这一行认出它是装配单而不是手写文档。

---

## 三种装配单

### 状态栏

| 字段 | 类型 | 必填 | 缺省 | 说明 |
| --- | --- | --- | --- | --- |
| 前端 | `状态栏` | 是 | — | 固定写 `状态栏` |
| 形态 | `placeholder` / `header` / `floating` | 否 | `header` | 三种形态见下文 |
| 预设 | 预设 id | 否 | — | tactical / gilded / terminal / cinema / sakura / washi / neon / custom |
| 标题 | 文本 | 否 | 空 | 显示在状态栏顶部 |
| 折叠 | bool | 否 | `true` | placeholder / header 默认折叠成一行摘要；floating 忽略 |
| 摘要 | 列表（0–4 项） | 否 | 空 | 折叠时露出的一行：`变量`、`显示` |
| 分页 | 列表（1–6 页） | 是 | — | 每页：`名称`（唯一）、`图标`（可选）、`区块`（至少一个） |
| 令牌 | 映射 | custom 时必填 | — | 只有 `预设: custom` 才写；键名以 `--` 开头 |

### 正文美化

| 字段 | 类型 | 必填 | 缺省 | 说明 |
| --- | --- | --- | --- | --- |
| 前端 | `正文美化` | 是 | — | |
| 预设 | 预设 id | 否 | — | |
| 根标签 | 标签名 | 是 | — | 正文格式的根标签（如 `content`） |
| 楼层 | 1–50 | 否 | 10 | 渲染最近几楼 |
| 状态头 | bool | 否 | `false` | 顶部嵌入 header 形态的状态栏 |
| 模块 | 列表 | 否 | 空 | 每项：`标签`、`角色`、`显示`（可选） |
| 对白 | 映射 | 否 | — | `玩家标记`：缺省 `#` |
| 自定义区块 | 列表 | 否 | 空 | 每项：`HTML`、`CSS`（可选） |
| 令牌 | 映射 | custom 时必填 | — | |

### 创角页

| 字段 | 类型 | 必填 | 缺省 | 说明 |
| --- | --- | --- | --- | --- |
| 前端 | `创角页` | 是 | — | |
| 预设 | 预设 id | 否 | — | |
| 标题 | 文本 | 否 | 空 | |
| 步骤 | 列表（1–8 步） | 是 | — | 最后一步应用自动加核对清单 |
| 写入 | 映射 | 否 | — | `世界书条目`（`名称`、`模板`）、`开场信息`、`初始变量` |
| 令牌 | 映射 | custom 时必填 | — | |

每步包含 `名称`、`自定义开局`（bool，缺省 false）、`字段`（至少一个）。

## 区块类型

十二种区块（`BLOCK_TYPES`），在分页的 `区块` 列表里用 `类型:` 指定：

| 类型 | 字段 | 适合的变量 | 渲染 |
| --- | --- | --- | --- |
| stats | `标题?`、`项[]`（`变量`、`显示?`、`格式?`） | 任意 | 标签/值网格；数值带范围显示 `62 / 100` |
| bars | `标题?`、`项[]` | 有范围的数值 | 胶囊进度条 |
| gauge | `标题?`、`项[]`（最多 4） | 有范围的数值 | SVG 弧形量表 |
| tags | `标题?`、`变量` | 列表/记录/文本 | 每个元素一个标签 |
| fold | `标题`、`默认展开?`、`区块[]` | — | 折叠面板（不可嵌套） |
| list | `标题?`、`变量`、`字段?`、`最近?`（缺省 5） | 列表/记录 | 按字段显示最近几条 |
| relation | `标题?`、`变量`（记录）、`字段`、`进度?` | 记录 | 关系卡：首字头像、字段、可带进度 |
| timeline | `标题?`、`变量`（列表）、`时间?`、`说明?`、`最近?`（缺省 6） | 列表 | 竖向时间线 |
| crisis | `标题?`、`变量`、`档位[]`（`至?`、`名称`、`色`: ok/warn/danger/accent） | 数值/枚举 | 档位条 |
| delta | `标题?`、`项[]` | 数值 | 变动徽章：与上次比较 |
| text | `标题?`、`变量?` 或 `文本?` | 文本 | 一段文字 |
| custom | `HTML`、`CSS?` | — | 原样插入 |

## 正文角色

十个角色（`BODY_ROLES`），写在正文美化模块的 `角色:` 里：

| 角色 | 渲染 |
| --- | --- |
| 页眉 | `<header>` |
| 章节 | `<h2>` |
| 场景 | 斜体段落 |
| 正文 | 按段落与对白显示 |
| 对白 | 同正文 |
| 独白 | 斜体、次级色 |
| 提示 | 虚线框提示 |
| 检定 | 等宽检定框 |
| 折叠 | 折叠面板 |
| 隐藏 | 不显示 |

## 创角字段类型

六种类型（`FIELD_TYPES`），写在步骤字段的 `类型:` 里：

| 类型 | 额外字段 | 渲染 |
| --- | --- | --- |
| 文本 | `提示?`、`必填?` | 单行输入框 |
| 长文本 | `提示?`、`必填?` | 多行文本域 |
| 单选 | `选项[]` | 单选按钮组 |
| 多选 | `选项[]`、`最多?` | 复选框组 |
| 滑杆 | `范围: [最小, 最大]` | 拉杆 |
| 人物列表 | `选项[]`、`最多?` | 人物选择器 |

每个字段可以加 `写入: /路径` 把值写进变量表。配合 `写入.初始变量: true`，提交时按路径写入 MVU。

## 三种状态栏形态

| 形态 | 位置 | 实例数 | 取舍 |
| --- | --- | --- | --- |
| placeholder | 每楼一个 iframe | 每楼一个 | 只在最新楼渲染，旧楼空白；独立存在 |
| header | 随正文美化嵌入每楼顶部 | 每楼一个 | 只在最新楼展开；需要正文美化开启 `状态头: true` |
| floating | 酒馆页面右下角悬浮球 | 一个实例 | 换聊天不消失；不占楼层空间；Shadow DOM 隔离 |

## 硬规则

1. **变量绑定**：装配单里每一个 `变量:` 路径都必须在变量表里存在，否则检查报 `variable-binding`。
2. **bars 与 gauge**：只接受有范围的数值变量（如 `[0, 100]`），否则 `sheet-invalid`。
3. **自定义区块**：`custom` 区块的 CSS 只能用令牌（`var(--名称)`），不能写具体色值（`#hex` 或 `rgb()`），否则 `sheet-invalid`。自定义区块不放 `<script>`。
4. **custom 预设**：选 `预设: custom` 时必须在装配单里写全 `令牌:` 映射（至少 `--bg`、`--panel`、`--line`、`--text`、`--text-2`、`--text-3`、`--accent`、`--accent-2`、`--ok`、`--warn`、`--danger`），否则 `sheet-invalid`。
5. **编译产物仍过质量检查**：装配单编译出的 HTML 文档照样经过前端质量检查（`frontendQuality`），包括对比度、交互反馈、手机宽度等。
6. **流式映射里的引号**：在 YAML 流式映射 `{ … }` 里，值如果含有 `{键}` 占位符，必须用引号包住（如 `字段: { 好感: '/人物/{键}/好感' }`）。块风格的值不需要引号。
7. **记录路径**：`relation` 等区块的 `变量` 指向记录本身的路径（如 `/人物`），`字段` 里的值路径包含 `{键}` 占位（如 `/人物/{键}/好感`）。
8. **自定义开局**：步骤里写 `自定义开局: true` 只是把这一步标成「玩家临时加的设定」（核对页照常列出）；它的文字不会自动写到任何地方。要写进去，就在 `写入.世界书条目.模板` 和 `写入.开场信息` 里放这一步字段的 `{键}` 占位（例如 `{补充}`），玩家没填时占位留空。
