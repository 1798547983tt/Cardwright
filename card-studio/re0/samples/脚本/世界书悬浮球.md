## 结构

```
常量层：TARGETS（uid + 名称 + 组）、GROUPS（组 id + 标题 + uid 列表 + 默认开启）
纯函数层：targetMatches / validateTargetEntries / applySelection / normalizePlacement
接口层：读世界书 → 校验 → 切换 → 写回
界面层：悬浮球（可拖动、记住位置）+ 面板（按组列出）+ 错误面板
```

逻辑层全是纯函数，接受「条目数组」返回「新的条目数组」，不碰接口——所以可以离线测试。这一点值得照搬。

## 关键片段一：分歧组写成常量表

```js
const TARGETS = [
  Object.freeze({ uid: 171, name: '菜月昴', group: 'protagonist' }),
  Object.freeze({ uid: 282, name: '菜月昴娘化', group: 'protagonist' }),
  Object.freeze({ uid: 4, name: '正文美化（完整版）', group: 'rendering' }),
  Object.freeze({ uid: 283, name: '正文美化（超级轻量版）', group: 'rendering' }),
];
const GROUPS = [
  Object.freeze({ id: 'protagonist', label: '主角分歧', uids: [171, 282], defaultOpen: true }),
  Object.freeze({ id: 'rendering', label: '正文回响', uids: [4, 283], defaultOpen: true }),
];
```

uid 和名称成对写死。uid 用来找，名称用来核对——这是下一段的前提。

## 关键片段二：先核对，再切换

```js
function validateTargetEntries(entries, targets = TARGETS) {
  if (!Array.isArray(entries)) throw new Error('世界书条目格式异常：应为数组。');
  return targets.map(target => {
    const matches = entries.filter(entry => Number(entry?.uid) === target.uid);
    if (matches.length !== 1) throw new Error(`世界书 UID ${target.uid} 缺失或重复（找到 ${matches.length} 个）。`);
    const entry = matches[0];
    if (String(entry?.name ?? '') !== target.name) {
      throw new Error(`世界书 UID ${target.uid} 名称不匹配：期望“${target.name}”，实际为“${String(entry?.name ?? '')}”。`);
    }
    return { ...target, enabled: Boolean(entry.enabled), entry };
  });
}
```

缺失、重复、改名三种情况都抛错，**不自动修复、不按名字兜底**。原注释里写得很清楚：名称在 uid 之后核对，这样 uid 被别的条目占用时，按钮不会悄悄指到另一条上去。

## 关键片段三：一组恰好开一条

```js
function applySelection(entries, uid, targets = TARGETS) {
  const target = targets.find(item => item.uid === Number(uid));
  if (!target) throw new Error(`未知的世界书控制 UID：${uid}。`);
  validateTargetEntries(entries, targets);
  return entries.map(entry => {
    const managed = targets.find(item => item.uid === Number(entry?.uid));
    if (!managed || managed.group !== target.group) return entry;   // 别组和非受管条目原样返回
    return { ...entry, enabled: managed.uid === target.uid };
  });
}
```

返回的是新数组，未受管的条目**原样返回**（连对象引用都不换）。写回一次完成，不是逐条开关。

## 可以学的

- uid + 名称双重核对，出错就停。
- 逻辑层写成纯函数，接受数组返回数组，可离线测。
- 只改自己那一组的 `enabled`，其他条目一律不碰。
- 悬浮球位置要按视口夹紧（`normalizePlacement`），换设备或旋转屏幕后不会跑到屏幕外。

## 不要学的

- 把这张卡的 uid 抄进新卡：uid 由制卡工坊分配，每张卡都不一样。
- 组名、条目名照搬：分歧组来自设计书。
