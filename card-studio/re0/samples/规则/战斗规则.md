# RE:0 战斗规则

战斗使用一次性 12d20（十二枚 d20）骰池。骰池由调用者预先提供；每次检定严格从左到右取一枚并返回剩余池，骰池耗尽即停止并报错，不在规则模块内生成随机数。

流程固定为：先叙述行动与环境，再进行一次 check，最后叙述结果。检定总值等于骰面加上全部逐项修正；差值小于 0 为失败，0–4 为成功，5–9 为强成功，10 以上为暴击。自然 1 必定失败；自然 20 仅在原等级不是失败时提升一级，最高为暴击，且不能绕过破阶限制。

## 战力等阶

共有七级，每级只有下位与上位。下位档值为 `(等级−1)×2+1`，上位档值为 `(等级−1)×2+2`。未定、未知、不入阶、非法位置或中位均返回空值，不猜测中位。

## 行动、距离与 DC

每个回合每名角色有一个主行动单位、一个移动单位，并可在受击时使用一次防御反应。战场至少有一名参战者；参战者 ID 必须是非空字符串且全场唯一。距离带依次为接触、近距、中距、远距；移动只能改变相邻距离带，特殊能力可另行声明。防御 DC 使用 `clamp(10 + 2*(def档-atk档)+reaction+cover, 2, 30)`，其中 reaction 为反应修正，cover 为掩体修正。

## 防守反应与伤害

闪避给防御 DC +2、伤害倍率 0、不可反击；格挡给 DC +0、承受伤害乘 0.5（向下取整）、不可反击；反击给 DC −2、承受伤害乘 1，并打开反击窗口。未知反应按无修正处理。

伤害基准先乘检定等级倍率：失败 0、成功 1、强成功 1.5、暴击 2；再应用格挡等防守倍率并向下取整。结果中的 multiplier 是等级倍率与防守倍率的最终乘积，伤害始终为非负有限数。若防守方比进攻方高至少两个完整等阶（档值差至少 4），且本次未满足破阶条件，伤害为 0，理由为“无法破阶”。

## 濒死

濒死检定中自然 20 立即存活并恢复 1 点生命；自然 1 计两次失败；普通成功累计一次成功，普通失败累计一次失败。累计三次成功进入昏迷，累计三次失败死亡，其余状态保持濒死。成功与失败计数在每次检定之间保留。

## 资源刻度

生命、伤势、体力、魔力、精神和门负荷均使用 0–100 刻度。生命降至 0 是濒死候选，需进入濒死流程；伤势达到 50 进入明显受伤，达到 75 进入重伤；体力、魔力或精神降至 0 表示对应资源耗尽；门负荷达到 75 发出危险预警，达到 100 视为过载。阈值用于叙述与限制，不替代具体技能效果。

## 资源与结束

行动额度、距离带、掩体、持续效果和濒死计数属于战斗资源，记录在 事件.当前战斗 中。战斗结束时先把最终生命、资源与伤势回写到主角档案或关系人物的长期字段，再把当前战斗恢复为空状态：参与者、先攻顺序、当前行动者、行动额度、距离、掩体、持续效果、濒死计数与最近一次检定全部清空。

## 死亡回归

只有当前世界中的菜月昴实际死亡才触发死亡回归。顺序必须是：确认实际死亡 → 以唯一死亡 ID（D01、D02……）去重 → 在同一 UpdateVariable 中 add 死亡记录、replace 最近一次死亡回归的死亡ID与直接原因、replace /轮回/指令/死亡回归 为 true → 本回合不再改动世界、主角档案、关系、事件、线索与资产。随后由轮回存档脚本从存档快照恢复六个容器、世界重启次数加一、改写轮回分支并清空当前战斗；模型不得自行执行这些恢复。濒死、昏迷、失踪、生死未卜、替身死亡、试炼影像、历史回溯、幻觉或未落地 IF 均不触发。
