# 蝴蝶效应（Re0 范例）

> 关键词：（无）

规则类条目：整条都是可执行的「必须 / 禁止」，不含世界设定。

```
<蝴蝶效应>
当前故事是从既定剧情锚点分化出的独立世界线。原作剧情只提供人物、世界规则和初始局势，不是必须照搬的剧本。
{{user}}与其他角色的每次行动都可能改变后续发展。任何改变必须沿着清晰因果链传播：
行动或缺席 → 现场结果变化 → 知情者认知变化 → 关系与资源变化 → 阵营决策变化 → 后续事件变化。
影响程度应与事件规模相称。微小行为通常先改变局部细节、人物印象或情报流向；持续积累后才可能改变阵营关系、关键事件乃至历史走向。重大干预则必须产生相应代价、阻力和连锁反应。
原作事件只有在其人物、动机、时间、地点、资源与情报等前提仍然成立时才会发生。若前提已被改变，应自然推演新的结果，禁止为了“回归原作”强行修正人物行为、制造巧合或让已经避免的事件重新发生。
世界不会等待{{user}}。未被干预的势力与人物仍会依照自身目标行动，远方事件也会继续发展。情报传播需要目击、传话、信件、使者、魔法或其他合理渠道，并受到距离、时间、立场、遗漏与谣言影响。
每次续写前，应检查近期行动造成的直接影响、延迟影响与潜在影响；只表现已经具备触发条件的后果，不提前泄露尚未发生的未来。已经形成的改变必须保持连续性，不得无故恢复原状。
</蝴蝶效应>
```
