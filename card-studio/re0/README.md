# Re0 范例库

内置的写法样本，供分区 AI 查阅。样本取自用户本人原创的《Re:从零开始的异世界生活》角色卡，**只收精选条目，不收全部 290 条**（ADR 0011）。

- 结构分析：[structure/世界书结构分析.md](structure/世界书结构分析.md)（Cardwright 原创整理）
- 样本目录：`samples/`

| 目录 | 内容 | 什么时候看 |
| --- | --- | --- |
| `samples/规则/` | 蝴蝶效应、防全知、叙事基调、战斗规则 | 写叙事规则时 |
| `samples/总览/` | 人物总览（已修正开头标签） | 写人物总览时 |
| `samples/设定/` | （阶段 3 补） | — |
| `samples/人设/` | 菜月昴、爱蜜莉雅、艾尔莎 | 做人物模板、写人物条目时 |
| `samples/剧情/` | 标题剧情索引、第 01 卷、第 05 卷 | 做剧情模板、写剧情条目时 |
| `samples/正文格式/` | 正文格式完整版 | 写正文格式时 |
| `samples/变量/` | 变量列表、初始变量、变量更新规则、变量输出格式 | 写世界书·变量、脚本·变量结构时 |
| `samples/脚本/` | MVU 与 ZOD（固定件与 Zod 写法）、世界书悬浮球 | 写脚本各分区时 |
| `samples/正则/` | 正文美化、状态栏、变量更新（两条）、开局创角向导 | 写正则各分区时 |

## 怎么用

- **学写法，不抄内容**。样本展示的是字段顺序、参数取法、句式密度和长度分布。本卡的世界观、人物和剧情都来自用户自己的资料。
- 每个样本文件的开头写着这条在原卡里的参数：触发方式、位置、顺序、uid、字数、关键词。世界书样本的正文在代码块里原样收录。
- 正则与脚本样本只收**结构分析与关键片段**，不整份收录（单个正则动辄十几二十万字符，整份放进来既读不完，也不利于学写法）。原文在用户的参考资料里，样本开头写明了位置。
- 样本里的问题也照原样保留并标注（例如人物总览原本把开头写成了 `</人物总览>`，这里修正并在文件里说明）。不要把原卡的问题当成范例。
